# 科研项目台账

这是一个本地运行的科研项目管理页面。适合记录 Idea、论文、案例、会议、项目、课题和资政报告。

## 使用方法

1. 解压整个文件夹，双击打开「科研项目台账.html」。
2. 点击「＋ 新建」，填写项目名称、类型、阶段等信息，然后保存。其他字段可以以后补充。
3. 在编辑页添加研究主题标签、任务、投稿历程和材料位置；卡片上的「查看详情」用于阅读完整信息。
4. 使用「主题关系图」查看自己填写的主题和作品之间的关联。

打开后为空白，页面不会自动读取电脑里的其他文件，也不会自动填入项目。

## 保存与备份

- 记录保存在**当前设备、当前浏览器**的本地存储中，不会随 HTML 文件一起传给别人，也不会自动同步到其他设备或浏览器。
- 请定期点击页面上的「导出备份」，将 JSON 文件保存在安全的位置。更换设备或浏览器时，在新页面点击「导入备份」并选择 JSON 文件。
- **导入会替换当前台账**。如果当前已有数据，先导出一份备份。
- 清除浏览器网站数据、使用无痕模式或重置浏览器可能导致记录丢失，请不要只依赖浏览器保存。
- 把 HTML 文件发给他人，不会包含你已填写的台账；不要把含个人信息的 JSON 备份一并发送，除非你希望分享这些数据。
- 推荐使用较新的 Chrome、Edge 或 Safari。查看页面和管理数据无需联网；打开网页链接需要网络。

## 功能提示

- 「项目工作台」按状态分区；可设置优先级、本周关注、任务和下一步。
- 「发表成果」集中展示成果类型、去向和日期；录用与发表／入库日期分别填写。
- 「投稿历程」按轮次记录刊物、投稿日期、反馈和备注，与当前投稿信息分别保存。
- 「回收站」可恢复已删除记录；永久删除前请确认已备份。
- 研究主题可以输入新标签，也可选择已经使用过的标签。同一作品可关联多个主题。
